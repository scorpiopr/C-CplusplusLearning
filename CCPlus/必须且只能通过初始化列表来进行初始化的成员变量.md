在 C++ 中，构造函数的初始化列表（Initialization List）具有非常特殊的底层语义：它是成员变量真正被创建并初始化的唯一地方。如果进入到构造函数的花括号 { } 内部，那就不叫“初始化”，而是叫“赋值（Assignment）”了。
因此，基于这一底层机制，有 3 种成员变量必须、且只能通过初始化列表来进行初始化：
------------------------------
## 1. 常量成员变量（const）

* 原因：const 修饰的变量具有只读属性，必须在创建的同时完成初始化，一旦创建完成，之后便无法再被修改（不能进行赋值操作）。
* 错误写法：

```cpp
class Test {
    const int a;
public:
    Test(int val) {
        a = val; // ❌ 编译报错：不能对 const 变量进行赋值
    }
};
```
* 正确写法：
```cpp
Test(int val) : a(val) { } //  正确：在初始化列表进行初始化
```

## 2. 引用成员变量（&）

* 原因：C++ 中的引用（Reference）在物理本质上是别名，必须在定义时强制绑定到一个合法的对象，且一旦绑定后就无法更改指向。
* 错误写法：
```cpp
class Test {
    int& ref;
public:
    Test(int& obj) {
        ref = obj; // ❌ 编译报错：引用未在初始化列表初始化
    }
};
```
* 正确写法：
```cpp
Test(int& obj) : ref(obj) { } //  正确
```

## 3. 没有默认构造函数的类类型成员变量（没有无参构造函数）

* 原因：如果一个类类型的成员变量没有默认构造函数（即必须带参数才能创建），编译器在执行构造函数花括号 { } 之前，无法盲目自动帮它调用无参构造函数去创建它。你必须在初始化列表中显式传参来引导它创建。
* 错误写法：
```cpp
class NoDefault {
public:
    NoDefault(int x) { } // 只有带参构造函数，没有无参构造函数
};
class Test {
    NoDefault nd;
public:
    Test(int val) {
        nd = NoDefault(val); // ❌ 编译报错：NoDefault 没有可用的默认构造函数
    }
};
```
* 正确写法：
```cpp
Test(int val) : nd(val) { } //  正确：显式调用带参构造
```

------------------------------
## 💡 衍生考点：子类继承时，父类没有默认构造函数
这个原则不仅适用于类的“成员变量”，同样完全适用于类的“派生/继承”体系：
如果父类（Base Class）显式定义了带参数的构造函数，而没有提供默认的无参构造函数。那么子类（Derived Class）的构造函数中，必须在初始化列表中显式调用父类的带参构造函数，否则编译直接失败。
```cpp
class Base {
public:
    Base(int x) { } // 没有默认构造函数
};
class Derived : public Base {
public:
    // ❌ 错误：编译器在进入 { } 前找不到 Base::Base()
    // Derived(int val) { } 

    //  正确：必须在初始化列表中显式初始化父类
    Derived(int val) : Base(val) { } 
};
```
