以下是一张为您梳理的 C++ 不同版本中聚合体初始化方式 的全景对比表：

| 初始化方式 | C++98 / 03 | C++11 / 14 | C++17 | C++20 / 23 / 26 | 语法示例与注意事项 |
|---|---|---|---|---|---|
| 传统拷贝初始化 | | | | | A a = {1, 2}; （最早期的 C 风格初始化） |
| 直列表初始化 | ❌ | | | | A a{1, 2}; （C++11 统一初始化语法） |
| 缺省成员初始化 | ❌ | ❌ | | | 允许在结构体内给变量赋初值（如 int x = 0;） |
| 带有基类的聚合 | ❌ | ❌ | | | 允许继承其他聚合体（如 struct B : A { int z; };） |
| 指定初始化 | ❌ | ❌ | ❌ | | A a{.x = 1, .y = 2}; （必须严格按声明顺序初始化） |
| 圆括号直接初始化 | ❌ | ❌ | ❌ | | A a(1, 2); （C++20 允许聚合体使用圆括号形式） |

------------------------------
## ⚠️ 版本间最核心的两个“天坑”规则变化：

   1. 用户声明构造函数的定义收紧（C++20）：
   * C++11 到 C++17：如果写了 A() = delete; 或 A() = default;，它依然算聚合体，可以用 {1, 2} 初始化。
      * C++20 起：只要有任何形式的用户声明（包括 = delete），它就不再是聚合体，导致上面的所有初始化方式全部失效！
   2. 指定初始化（Designated Initializers）的顺序限制（C++20）：
   * C++20 的指定初始化看似像 C 语言，但有严格限制：必须严格按照结构体中变量声明的顺序来写。
      * 例如 struct A { int x; int y; };，写 A a{.y=2, .x=1}; 在 C 语言中合法，但在 C++ 中属于语法错误。
