在计算机网络中，IP 地址的分类主要分为两大体系：传统的有类划分（Classful Addressing）和现代的无类划分（Classless Addressing / CIDR）。
在笔试和面试中，考官通常会重点考察传统五类 IP 的划分范围，以及如何利用子网掩码进行现代 IP 计算。
------------------------------
## 📌 体系一：传统的有类划分（A、B、C、D、E 五类）
传统的有类网络根据 IP 地址 第一个字节（前 8 位）的前几位固定二进制 进行了硬性划分：

| 网络类别 | 前缀固定二进制 | 第一个字节范围 (十进制) | 默认子网掩码 | 适用场景 |
|---|---|---|---|---|
| A类 | 0 | 1 ~ 126 | 255.0.0.0 | 大型网络（包含极多主机，少量的网络数） |
| B类 | 10 | 128 ~ 191 | 255.255.0.0 | 中型网络（中等规模的学校或跨国企业） |
| C类 | 110 | 192 ~ 223 | 255.255.255.0 | 小型网络（小企业、普通的局域网） |
| D类 | 1110 | 224 ~ 239 | 无默认掩码 | 组播地址（Multicast，一对多广播） |
| E类 | 1111 | 240 ~ 255 | 无默认掩码 | 保留地址（科研、实验和未来使用） |

## ⚠️ A类范围为什么漏掉了 0 和 126 后面的 127？（面试常考）

* 0.0.0.0：代表“任意网络”或“未知本机 IP”，不能做普通主机 IP。
* 127.0.0.1 ~ 127.255.255.254：属于环回地址（Loopback Address），专门用来测试本机的网络协议栈（最常见的就是 localhost 绑定的 127.0.0.1）。

------------------------------
## 🔒 体系二：按使用性质分类（公网 IP vs 私网 IP）
为了缓解 IPv4 地址耗尽的危机，人们从 A、B、C 三类地址中各自抠出了一部分，专门在局域网内部重复使用，称为私网 IP（Private IP）。私网 IP 在互联网上无法直接路由，必须通过 NAT（网络地址转换） 技术转成公网 IP 才能上网。

* A类私网地址：10.0.0.0 ~ 10.255.255.255
* B类私网地址：172.16.0.0 ~ 172.31.255.255
* C类私网地址：192.168.0.0 ~ 192.168.255.255（你家里的 WiFi 路由分配的通常就是这个）

------------------------------
## 🌐 体系三：特殊的 IP 地址（笔试陷阱题常客）
除了上面扣掉的 127 网段，以下特殊 IP 在计算有效主机数时也要特别防范：

   1. 主机位全 0：网络地址，代表该网段本身（如 192.168.1.0）。
   2. 主机位全 1：定向广播地址，用于向该网段内所有主机发广播（如 192.168.1.255）。
   3. 255.255.255.255：受限广播地址，数据包不会跨越路由器，只在本物理网段内进行广播。
   4. 169.254.X.X：自动专用 IP 地址（APIPA）。当你的电脑开启了自动获取 IP（DHCP），但本地路由器或 DHCP 服务器死机时，Windows 会自动给自己胡乱分配一个这样的地址，此时你通常是上不了网的。

------------------------------
## 🚀 现代化演进：无类域间路由（CIDR）
因为传统分类（如 A 类一个网段能容纳 1600 万台主机，C 类只能容纳 254 台）太粗暴，导致了巨大的地址浪费。
现代计算机网络早已抛弃了默认的 A/B/C 分类，改用 CIDR（无类域间路由）。通过在 IP 后面加斜杠（如 192.168.1.100/26），直接通过掩码中 1 的个数来灵活定义网络号的长度。
