# 什么是C类地址
C类IP地址（Class C IP Address）是传统IPv4分类网络结构中的一种地址类型，主要用于小型局域网络。
核心特征
 * 地址范围：192.0.0.0 ～ 223.255.255.255
 * 首字节二进制特征：最高三位固定为 110（即 11000000 到 11111111）
 * 默认子网掩码：255.255.255.0（或 /24）
 * 结构划分：24位网络号 + 8位主机号（前三个字节标识网络，最后一个字节标识主机）
容量与数量
 * 最大网络数：2^{21} = 2,097,152 个网络（前3位固定，剩余21位用于网络标识）
 * 每个网络的最大主机数：2^8 - 2 = 254 台主机
   * 注：扣除2个特殊地址——主机号全为0的**网络地址（如 192.168.1.0）**和主机号全为1的**广播地址（如 192.168.1.255）**。
私有与特殊地址
C类地址中包含一段专用于局域网内部通信的私有地址（Private Address）：
 * 私有地址范围：192.168.0.0 ～ 192.168.255.255（包含256个C类子网，常用于家庭路由器和企业内网）
 * 环回地址/测试：位于以 127 开头的地址（保留用于 Loopback）
常见应用场景
由于一个C类网络最多容纳254台设备，它非常适合小型企业、家庭网络以及学校实验室等局域网环境。在现代网络中，虽然传统的ABC分类已被 CIDR（无类域间路由） 替代，但 /24 掩码和 192.168.X.X 段依然是最常见的网络划分方式。

# 子网划分
C类IP地址的子网划分（Subnetting），本质上是通过 **向主机位“借位”** 来充当额外的网络位（称为子网位），从而将一个大的C类网络拆分为多个较小的子网。
1. 核心计算公式与概念
C类地址的默认子网掩码为 255.255.255.0（/24），后8位为主机位。假设向主机位借 n 位作为子网位：
 * 借位位数 (n)：从第4个字节的最高位（左侧）开始连续借 n 位（1 \le n \le 6）。
 * 划分子网数：2^n（可以划分出 2^n 个子网）。
 * 每个子网的主机位剩余：8 - n 位。
 * 每个子网可用的有效主机数：2^{8-n} - 2（扣除网络地址和广播地址）。
 * 子网块大小（步长/Block Size）：2^{8-n}（每个子网地址段的跨度大小）。
 * 新子网掩码：前24位全为1，再加上借来的 n 个1。
2. 经典计算示例
需求：将C类网络 192.168.1.0/24 划分成 4个子网。
第一步：计算借位位数 n
 * 要得到 4 个子网，需要 2^n = 4 \implies n = 2。
 * 即向主机位借 2位。
第二步：确定新子网掩码
 * 原掩码：255.255.255.0 (11111111.11111111.11111111.00000000)
 * 新掩码（借2位）：11111111.11111111.11111111.11000000
 * 转换成十进制：128 + 64 = 192 \implies 255.255.255.192（或 CIDR 记法 /26）。
第三步：计算步长与地址范围
 * 剩余主机位数：8 - 2 = 6 位。
 * 每个子网步长（跨度）：2^6 = 64。
 * 每个子网可用主机数：2^6 - 2 = 62 台。
第四步：列出各个子网的具体范围
| 子网编号 | 子网地址（网络号） | 第一个可用IP | 最后一个可用IP | 广播地址 |
|---|---|---|---|---|
| 子网 1 | 192.168.1.0 | 192.168.1.1 | 192.168.1.62 | 192.168.1.63 |
| 子网 2 | 192.168.1.64 | 192.168.1.65 | 192.168.1.126 | 192.168.1.127 |
| 子网 3 | 192.168.1.128 | 192.168.1.129 | 192.168.1.190 | 192.168.1.191 |
| 子网 4 | 192.168.1.192 | 192.168.1.193 | 192.168.1.254 | 192.168.1.255 |

# 子网掩码
在计算机网络中，子网掩码（Subnet Mask） 的核心作用就一句话：它是一把“尺子”，用来帮计算机把一个 IP 地址切分成“网络号”和“主机号”两部分。
通过这把尺子，计算机能够判断目标 IP 地址究竟是在同一个局域网内（内部通信），还是在其他网络中（需要找路由器转发）。
## 🛠️ 子网掩码的四大具体作用
### 1. 划分网络号与主机号
IP 地址表面上是一串连续的数字，计算机必须依靠子网掩码才能识别结构。

* 网络号（Network ID）：代表你所在的“车间”（网段）。
* 主机号（Host ID）：代表你在车间里的“工号”（具体设备）。

### 2. 判定是否在同一网段（同子网）
当你的电脑（源 IP）想给另一台电脑（目的 IP）发送数据时，它会进行以下操作：

   1. 将自己的 IP 和子网掩码进行 与运算（AND），算出自己的网络号。
   2. 将目的 IP 和子网掩码进行 与运算（AND），算出目的网络号。
   3. 对比结果：
   * 相同：说明对方和自己在同一个局域网，数据包直接通过交换机“直达”。
      * 不同：说明对方在远端网络，数据包必须发送给“网关（路由器）”进行转发。
   
### 3. 实现子网划分（Subnetting）
为了避免 IP 地址浪费和广播风暴，企业通常会将一个大的标准网络（如 C 类网络，有 254 个地址）通过修改子网掩码，向主机位“借位”，从而切割成多个更小的子网。

* 例如：把 255.255.255.0 改为 255.255.255.128，就能把一个大网络平分成两个各有 126 个可用地址的小子网。

### 4. 简化路由表（路由聚合 / CIDR）
路由器在转发数据时，不需要记录互联网上每一台电脑的 IP，只需要记录子网掩码划分出来的“网络号”。这样可以极大地减少路由器内存的消耗，提高转发效率。

## 🔍 核心原理：二进制“与运算（AND）”
子网掩码必须和 IP 地址成对出现，它的二进制特征非常简单：左边全是 1（代表网络位），右边全是 0（代表主机位）。
假设一台主机的 IP 是 192.168.1.100，子网掩码是 255.255.255.0：
```
IP 地址:   11000000.10101000.00000001.01100100  (192.168.1.100)
子网掩码:  11111111.11111111.11111111.00000000  (255.255.255.0)

-----------------------------------------------------------------
AND运算:   11000000.10101000.00000001.00000000  (192.168.1.0 -> 算出的网络地址)
                                      └────┘
                                      主机位被0清空，只剩网络号
```

## ⚠️ 面试/求职笔试必背常识

   1. 无类域间路由（CIDR）表示法：
   在开发或日常配置中，我们常看到 192.168.1.100/24。这里的 /24 就是子网掩码的简写，表示子网掩码二进制中前 24 位全部是 1，等同于 255.255.255.0。
   2. 全 1 和全 0 的连续性：
   子网掩码的二进制必须是连续的 1 和连续的 0（例如 255.255.255.240 是合法的）。绝对不能 1 和 0 交错出现（如 255.255.255.161 转换成二进制会断开，是非法的）。
